# Бизнес-требования к приложению Business Metrics Analyzer

## 1. Цель приложения

Автоматизировать расчёт и анализ ключевых показателей эффективности (KPI) предприятия, чтобы сократить время подготовки отчётности и снизить риск ошибок при ручных расчётах.

## 2. Заинтересованные стороны

- руководитель предприятия — получает сводные показатели для принятия решений;
- финансовый аналитик — загружает данные и рассчитывает показатели;
- разработчики — поддерживают и развивают приложение.

## 3. Бизнес-требования

1. Приложение должно принимать данные о выручке и затратах по месяцам.
2. Приложение должно рассчитывать среднюю выручку за период.
3. Приложение должно рассчитывать рентабельность в процентах.
4. Приложение должно рассчитывать рост выручки между периодами.
5. Результаты должны выводиться в понятном виде (таблица, при необходимости график).
6. Расчёты не должны завершаться ошибкой при нулевой выручке.

## 4. Ограничения

- язык разработки: Python 3.10+;
- используемые библиотеки: pandas, matplotlib;
- файлы с данными (`*.csv`, `*.xlsx`) не хранятся в репозитории.

## 5. Критерии успеха

- показатели рассчитываются корректно на тестовых данных;
- проект запускается по инструкции из `README.md` на чистом окружении;
- изменения вносятся через ветки и Pull Request.
