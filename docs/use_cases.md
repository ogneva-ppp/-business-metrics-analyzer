# Use Case диаграмма и описание

Диаграмма: `docs/use_case_diagram.png` (исходный код: `docs/use_case_diagram.puml`).

## Акторы

- Коммерческий директор
- Менеджер по продажам
- Аналитик
- Администратор системы

## Use Case 1. Формирование отчёта

| Поле | Значение |
|---|---|
| Название | Формирование отчёта |
| Актор | Аналитик |
| Предусловие | Пользователь авторизован, данные загружены |
| Основной поток | 1. Пользователь выбирает тип отчёта.<br>2. Указывает период.<br>3. Нажимает «Сформировать».<br>4. Система формирует отчёт.<br>5. Пользователь просматривает отчёт. |
| Альтернативный поток | Если данных за период нет, система выводит сообщение |
| Постусловие | Отчёт сформирован и доступен для экспорта |

## Use Case 2. Загрузка данных о продажах

| Поле | Значение |
|---|---|
| Название | Загрузка данных о продажах |
| Актор | Менеджер по продажам |
| Предусловие | Пользователь авторизован, есть файл с данными о продажах |
| Основной поток | 1. Пользователь открывает раздел загрузки данных.<br>2. Выбирает файл.<br>3. Нажимает «Загрузить».<br>4. Система проверяет формат и записывает данные.<br>5. Система сообщает об успешной загрузке. |
| Альтернативный поток | Если формат файла неверный, система выводит сообщение об ошибке и не загружает данные |
| Постусловие | Данные о продажах сохранены и доступны для расчёта KPI |
